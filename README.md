## Projects
 
- **[engineering-thesis](https://github.com/lbrza/engineering-thesis):** C# implementations of three lightweight cryptographic hash functions (Photon, Quark and Spongent), benchmarked on a desktop and a Raspberry Pi. Master's thesis, UADE, 2021.
- **[TourGuide Megaphone](https://github.com/th-aslam0/W24_3175_G1_TourGuideMegaphone):** Course prototype of an Android app (Java) for booking live-streamed virtual tours with local guides. Built with a classmate for CSIS 3175 at Douglas College, Winter 2024. I built the currency converter, which uses Retrofit to fetch rates from a public exchange-rate API and caches them in SQLite until the provider's next scheduled update, to stay within the API's rate limit. I also built a location-based city quiz: it finds the user's city with Google's fused location provider and reverse geocoding, loads questions for 10 cities from SQLite, and falls back to a city picker when the user's city isn't covered.
